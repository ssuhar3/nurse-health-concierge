Text message program

This section describes our only text message program. It is an internal program for our own workforce, and it is not open to the public.

Program name Legacy Senior Advocates Staff Portal Verification
What it does Sends a one time login code by text message so an employee or contracted advocate can sign in to our internal staff portal. Each code expires after 10 minutes.
Who receives messages Employees and contracted advocates of Legacy Senior Advocates only. We do not send text messages to clients, family members, or the public, and there is no public sign up.
How to join An advocate gives us their mobile number when their staff account is created, then requests a code by entering that number on the portal login screen and choosing to receive a code by text. A message is sent only in response to that request. We never send an unprompted message.
Message frequency Messages are sent only when a code is requested, so frequency varies with how often an advocate signs in. In practice this is roughly 1 to 10 messages per month per person.
Cost Message and data rates may apply. We do not charge for the program. Your mobile carrier's normal rates apply.
To stop messages Reply STOP to any message. You will receive one confirmation and then no further messages. You can still sign in using an emailed login link. To start again, request a code from the login screen.
To get help Reply HELP to any message, or email info@lsadvocates.com.
Carriers Carriers are not liable for delayed or undelivered messages. Delivery is not guaranteed, and codes may be delayed by network conditions.
Privacy No mobile information will be shared with third parties or affiliates for marketing or promotional purposes. See our Privacy Policy.
